# Medical Image Analysis

**Instructors:** H. DELINGETTE and X. PENNEC  

## Project Overview

This repository contains the coursework for the Medical Image Analysis course. It consists of a paper review, written in French. 

The reviewed paper is [A geometric approach to robust medical image segmentation](https://doi.org/10.1016/j.media.2024.103260) by Ainkaran Santhirasekaram, Mathias Winkler, Andrea Rockall, and Ben Glocker.

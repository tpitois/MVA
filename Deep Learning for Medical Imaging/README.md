# Deep Learning for Medical Imaging

**Instructors:** O. COLLIOT and M. VAKALOPOULOU  

## Project Overview

This repository contains the coursework for the Deep Learning for Medical Imaging course, divided into two main parts:

### 1. Medical Imaging Challenge
The practical part focuses on the **classification of histopathology patches from diverse clinical sites**. The goal is to build a robust deep learning model that generalizes well across variations from different clinical environments.

### 2. Paper Review
The theoretical component consists of a critical review and a poster presentation of the paper [Paired Image Generation with Diffusion-Guided Diffusion Model](https://arxiv.org/pdf/2507.14833).

# Master MVA Projects

This repository contains projects, implementations, and paper reviews completed during my [Master MVA](https://www.master-mva.com/) (Mathematics, Vision, Learning) at ENS Paris-Saclay.

---

## [Deep Learning for Medical Imaging](https://github.com/tpitois/MVA/tree/main/Deep%20Learning%20for%20Medical%20Imaging)
**Instructors:** O. COLLIOT, M. VAKALOPOULOU  
This folder contains a deep learning challenge on the robust classification of histopathology patches across diverse clinical sites, alongside a critical review of *Paired Image Generation with Diffusion-Guided Diffusion Model*.

## [Deformable Models & Geodesic Methods](https://github.com/tpitois/MVA/tree/main/Deformable%20models%20and%20geodesic%20methods%20for%20image%20analysis)
**Instructor:** L. D. COHEN  
This project features an implementation of *Finsler-Laplace-Beltrami Operators with Application to Shape Analysis*, exploring 3D heat diffusion and neural networks for shape correspondence on the TOSCA dataset.

## [Geometric Data Analysis](https://github.com/tpitois/MVA/tree/main/Geometric%20Data%20Analysis)
**Instructor:** J. FEYDY  
This section focuses on a 2D reproduction of *Modeling the Shape of the Brain Connectome via Deep Neural Networks*, tested on synthetic vector fields and real-world HCP data.

## [Medical Image Analysis](https://github.com/tpitois/MVA/tree/main/Medical%20Image%20Analysis)
**Instructors:** H. DELINGETTE, X. PENNEC  
This directory contains a comprehensive paper review (written in French) of *A Geometric Approach to Robust Medical Image Segmentation*.

> **Note:** Click on the course titles to access the specific folders containing the detailed reports, posters, and Jupyter notebooks.
